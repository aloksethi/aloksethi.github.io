## Module pin out
[pin out ref for 36 pin gpios](https://randomnerdtutorials.com/esp32-pinout-reference-gpios/). For the 30 pin version, following pins are missing `CMD, SD3, SD3, SD0, SDI, and D0`. Further, `Clk` seems to be replaced with `Gnd`.

### via idf.py
Can launch both gdb and openocd together or independently via `idf.py`. Independently launching gdb via `idf.py gdb` and openocd via `idf.py openocd`
`cd /datadisk/esp_tests/blink/`. There is possibility of running both in one go but it hijacks the terminal n i didnlt like it.



## Programming via idf
set the varialbes via either
```shell
. $HOME/esp/esp-idf/export.sh
```
or
```shell
get_idf
```
```
cd ~/esp/hello_world
idf.py set-target esp32
idf.py menuconfig
idf.py build
idf.py -p PORT flash
```
Replace PORT with your ESP32 board's USB port name`/dev/ttyUSB0`. If the PORT is not defined, the idf.py will try to connect automatically using the available USB ports.
